Lua API

Put scripts in Documents\Lambda\Luas\. Lambda uses LuaJIT — standard Lua 5.1 syntax with FFI available. Load them from the Scripts tab inside the menu.

Example — ESP label on every enemy
local font = render.add_font("Tahoma", 13)

client.add_callback("render", function()
  for i = 1, globals.max_players do
    local pl = entity.get(i)
    if not pl then goto continue end
    if not pl:is_alive() or not pl:is_enemy() then goto continue end

    local sx, sy, vis = render.world_to_screen(pl:get_eye_position())
    if vis then
      render.text(font, sx, sy - 14, color(255, 75, 75), pl:get_name(), true)
    end

    ::continue::
  end
end)

Compile it yourself

The release binary is built from this exact source. Nothing is added or removed.

git clone https://github.com/bestluaucoder/Lambda
cd Lambda\Lambda-master

"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe" ^
  Lambda.sln /p:Configuration=Release /p:Platform=x86 /m

  Lambda.vcxproj -> Release\Lambda.dll
