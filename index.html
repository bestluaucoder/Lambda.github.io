Compile it yourself

The release binary is exactly what this produces. Nothing else is added to it.

git clone https://github.com/ryknuq/Lambda
cd Lambda
MSBuild Lambda.vcxproj -p:Configuration=Release -p:Platform=Win32

  Lambda.vcxproj -> release\Lambda.dll

TargetWindows, 32-bit
